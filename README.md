# Universal Paperclips

Clean-room reimplementation built from the specification in `docs/spec/` and the
product requirements in `docs/product/requirements.md`.

Status: milestone 1 (core) in progress. The spec 01 §1 formatters and the
§2 initial state are implemented and tested; the remaining core modules are
typed stubs and the command-line harness is not implemented.

## Requirements

- Bun 1.4 or newer

## Install

```sh
bun install
```

## Check

Runs lint, type checks and tests:

```sh
bun run check
```

## Command-line harness

```sh
bun run cli
```

The harness is not implemented yet.
